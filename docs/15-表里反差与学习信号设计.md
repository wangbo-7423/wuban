# 15 · 表里反差揭示式讲解与学习信号设计

> 本文回答：**一个关于「深度思考」的洞察（会主动关联看似无关的东西；拿着表层的视角把深层描述出来，反差拉满幽默感），如何落成产品的教学动作与观测信号——讲解怎么讲、反应怎么记、关联怎么沉淀、怎么反哺下一轮讲解。**
> 本文是 [00-产品定位与认知科学设计](./00-产品定位与认知科学设计.md) §5.1 的展开；讲解行为真源在 `prompts/guide_concept.md`，观测真源在 `backend/app/services/memory_service.py` 的抽取约定。

## 1. 洞察 → 理论对照

起点是对「深度思考的人是什么样」的一段思考，它独立复现了认知科学里两个有名结论：

| 洞察 | 对应理论 | 关键等式 |
| --- | --- | --- |
| 「连接看似无关实则有关的东西」 | Koestler **双联联想**（bisociation）：创造力与幽默共享同一机制——两个各自自洽、习惯上互不相干的框架相撞 | 撞出「啊哈」也撞出「哈哈」 |
| 「表层看着没事、深层有点荒诞；**拿着表层的视角把深层描述出来**，幽默感拉满」 | 幽默研究**失谐—解困理论**（incongruity-resolution）：幽默 = 期望违背 + 随后消解 | 「消解期望违背」就是「图式更新」本身——**「啊哈」和「哈哈」在认知操作上是同一个动作** |

第二条里的加粗部分是后来修正的关键：幽默强度取决于**叙述视角**，不是反差本身——指出反差是说教，用表层口吻描述深层才是幽默。这决定了 §2 的手法设计。

对本产品的意义：它的第一性依据是认知心理学（docs/00 §4），这个洞察可以直接落成机制，而不是当情怀；同时它补上了「学长型学伴」里最「人」的部分——与通用助手的单轮差异里，最难被提示词仿掉的就是「这个学伴会觉得某些概念好玩、有自己的温度」。

## 2. 教学动作：表里反差揭示式讲解

### 2.1 适用判据：双层结构概念

概念有「表层无辜、深层离谱」的结构——表层听着人畜无害，深层事实近乎荒诞：

| 概念 | 表层 | 深层 |
| --- | --- | --- |
| `0.1 + 0.2` | 小学加法 | 机器里根本没有 0.1 这个数，你看到的是它修饰过的样子 |
| `gets()` | 最顺手的读入函数 | 它放进来过整个互联网的蠕虫（Morris worm） |
| `sleep(1)` | 睡一秒 | 睡多久全凭调度器施舍 |
| NaN | 数总该等于自己 | `NaN !== NaN`，荒诞但自洽 |

概念本身没有双层结构就**不适用**（如「进程 vs 线程」）——克制是本设计的生命线。

### 2.2 手法：三步揭示（真源 `prompts/guide_concept.md`）

1. **先正经立起表层**：把学生直觉以为的样子原样立住，承认它合理；
2. **不换腔调，讲深层**：继续用表层那套日常词汇，认真地把深层事实说完——全程不喊「荒诞」、不点破、不自己笑，反差自己会说话；
3. **收口交还**：抛一句引申疑问，让学生自己走进深层（衔接 Agent.md 规则 7）。

实测示例（GLM 5.3 Flash，`reveal_sanity` 真实输出）：

> 「它就在二进制里挑一个离 0.1 **最近**的、能在 64 位里写下的邻居，凑合给你用。你屏幕上打印出来的 0.1，其实是它替你四舍五入修饰后的样子。」「它不是算错了，而是它从头到尾算的就不是 0.1 + 0.2，是两个邻居的和——**算得非常准**。」

### 2.3 红线

- 反差必须从**概念结构本身**长出来，禁止外挂段子/谐音梗/网络梗——认知负荷研究明确：与材料无关的幽默是外在负荷，伤学习；
- **不点破幽默**：学生没 get 到就正常补讲，**绝不解释笑点**；
- 一个概念最多用一次。

### 2.4 落地位置与缓存安全

- 行为真源：`prompts/guide_concept.md` §表里反差（渐进式披露：随 `kg_lookup` 装配注入，概念/数学/工程场景生效）；
- 接线：`kg_lookup` ToolSpec 声明 `guide="guide_concept.md"`（`backend/app/agent/tools.py`）。**修复了一个历史问题**：该指南文件此前没有任何 spec 声明，是孤儿文件，从未进过注入链路；
- 指南走尾部动态上下文，`Agent.md` 未动——system 前缀缓存不受影响，无需重跑 `cache_sanity`；
- 刻意**不新增第五策略档位**：KG 四策略权重是守门测试写死校验的（`test_kg.py`「四策略权重齐全」），本动作语义上就归类比/反例的叙事结构，零 schema 变更。

## 3. 幽默即零压力理解探针

一个表里反差的梗，**只有建立了深层图式的人才可能 get 到荒诞在哪**。因此揭示式讲解天然是一次形成性评估：

- 接住了（会心、顺着玩梗、追问深层）= 深层图式已建立；
- 没 get 到 = 还没落地，正常补讲——「不好笑」不是「答错了」。

它没有出题、没有判分，形式比反问还隐蔽，完全守住 docs/00 §6「绝不扮演考官」的定位红线。学生接没接住本身就是信号，于是有了 §4。

## 4. 观测侧：三个学习信号

这些信号过去沉没在对话流里，现在进记忆抽取约定（`memory_service._EXTRACT_SYSTEM`），随聊天后台异步抽取，走既有 MCP 知识图谱通路，零新增表：

| 信号 | 触发条件 | 图谱形态 | 消费路径 |
| --- | --- | --- | --- |
| **兴趣** | 学生表达兴趣/兴奋（「这个太有意思了」），只有学生表达才抽，不替他决定 | 新增实体类型 `entityType=兴趣`（受控词表第 5 类） | L0 常驻层「觉得有意思的：…」；`cognitive_state.interests`；前端侧栏「✦ 觉得有意思」 |
| **自发关联** | 学生**主动**把两个看似无关的东西连上（「诶这像不像……」）；导师自己打的比方是普通「相关」 | `relationType=自发关联` 关系 | L1 一步邻接关系自然带出；探索档案最强的迁移证据 |
| **表里反差探针** | 导师用了揭示式讲法后学生接没接住 | 概念实体 observation：「表里反差探针：接住 / 未接住」 | 探索档案过程性证据；「未接住」提示下次补讲 |

数据流：

```
对话（导师揭示式讲解 + 学生反应）
  → 聊天后异步抽取（memory_service.extract_and_write，GLM JSON）
  → MCP 记忆图谱（兴趣实体 / 自发关联关系 / 探针 observation）
      ├─ 读路径：L0 常驻层注入「觉得有意思的」+ 使用要求「打比方可优先往他觉得有意思的方向连」
      │          L1 按需注入命中概念及其邻接（含自发关联）
      ├─ 画像回推：profile_service → cognitive_state.interests（docs/04 真源已同步）
      └─ 前端：SidePanel「我的记忆图谱」区展示 ✦ 兴趣标签
  → 下一轮讲解行为改变：往他感兴趣的方向类比、避开没接住的讲法——人格温度的记忆锚点
```

## 6. 验证结果（2026-09-03 实测）

- pytest **224 passed**（含新增 7 个）；vue-tsc 通过；`memory_context_sanity` 通过（L0 带出兴趣、概念仍被正确挡在 L0 外）；
- `reveal_sanity` 真实 GLM：指南注入确认；`0.1+0.2` 走出完整揭示式结构且不点破；`进程 vs 线程`（无双层结构）克制不硬造；
- `memory_extract_sanity` 真实 GLM+MCP 三轮：**兴趣 3/3、自发关联约 2/3、探针（加强措辞后）命中**。抽取是概率性的（temperature 0.2），脚本如实标 MISS 供人工判断。

## 7. 已知边界与未来工作

- **抽取确定性**：三信号命中率未到 100%，如需提升，优先在抽取 prompt 加一个 few-shot 小例子（每次抽取多 ~200 token，后台任务可接受）；不做硬校验拦截——误删一条真实信号比多记一条噪音伤害大；
- **探针信号依赖显性反应**：学生不回应下一轮就没有信号，「未接住」与「无数据」当前不做区分（observation 只在有反应时产生）；
- **自发关联暂不特殊加权**：L1 把它当普通邻接关系注入；若后续证明其对引导质量有区分度，再考虑在 L1 排序中加权（需评测集说话，对齐 docs/12 的红线）；
- 图谱可视化（如前端关系图）可后续把「自发关联」边渲染成不同颜色——学生视角最动人的一条边。

## 8. 答辩口径

一句话版本：**我们让 AI 用「拿着表层视角描述深层」的方式讲那些「表层无辜、深层荒诞」的概念——幽默在这里不是装饰，而是失谐—解困的认知操作本身：学生笑出来的瞬间就是图式更新的瞬间。讲完之后，接没接住、他自己连到了什么、觉得什么有意思，全部沉淀进记忆图谱与探索档案，下一轮讲解因此更懂他——这是通用助手付不起的代价：它的商业目标要求立刻给答案，而教学要求敢于让学生先「不舒服」一下。**
