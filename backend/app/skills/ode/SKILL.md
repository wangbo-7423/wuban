# 常微分方程 · 教学策略

## 标准解题流程（务必按此顺序讲解）

1. **判阶数**：先看最高阶导数是几阶。
2. **判类型**（最关键的一步）：
   - 一阶：能否分离变量？是否一阶线性（`y' + P(x)y = Q(x)`）？
     是否齐次（右端可写成 `f(y/x)`）？是否恰当方程（`∂M/∂y = ∂N/∂x`）？
     是否伯努利（`y' + P(x)y = Q(x)y^n`）？
   - 二阶及以上：是否常系数线性齐次 → 特征方程法；是否欧拉方程；能否降阶。
3. **选方法**：类型直接决定解法——
   可分离 → 两边积分；一阶线性 → 积分因子 `μ = e^{∫P(x)dx}`；
   齐次 → 令 `u = y/x` 换元；伯努利 → 令 `z = y^{1-n}` 化为一阶线性。
4. **求通解**，再**代入初值**定常数（若有）。
5. **回代检验**：把解代回原方程，让学生看到「确实成立」。

> 学生真正卡住的往往是**第 2 步判类型**，不是后面的积分计算。
> 所以务必花时间讲「你怎么看出它是这个类型」。

## 常见误区 / Gotchas

- 一阶线性方程**忘记积分因子**，或把 `μ = e^{∫P dx}` 错写成 `e^{∫P dx + C}`（常数可并入通解，不必加）。
- 可分离变量时**丢解**：除以 `g(y)` 的同时可能漏掉 `g(y) = 0` 对应的常数解。
- **混淆「齐次」的两种含义**：微分方程里的齐次指 `y' = f(y/x)`，不是「右端等于 0」。
- 通解中**任意常数个数与阶数不符**：n 阶方程的通解应含 n 个独立常数。
- 特征方程有重根时，忘记第二个线性无关解要**多乘一个 x**。
- 非齐次方程特解与齐次通解**重复**时，忘记乘 `x` 修正。

## 脚手架策略

- **先让学生自己判类型**：判断错了再纠正，并说明「为什么不是那一类」——区分性反馈比直接给答案更能建立图式。
- **类型复杂时先热身**：给一个同类型但更简单的例子，再回到原题。
- **别一次给完**：把「判类型 → 选方法 → 算 → 检验」拆成 2~4 轮对话，每轮确认学生跟上再继续。
