# 一阶 ODE 类型判别与解法速查

判类型的顺序建议：**先试可分离 → 再看是否线性 → 再判齐次 → 再验恰当 → 最后伯努利**。

| 类型 | 标准形式 | 判别要点 | 解法 |
|---|---|---|---|
| **可分离** | `y' = f(x)·g(y)` | 右端能拆成「只含 x」×「只含 y」 | 分离变量，两边各自积分 |
| **一阶线性** | `y' + P(x)y = Q(x)` | `y` 和 `y'` 都是**一次**、无乘积 | 积分因子 `μ = e^{∫P(x)dx}` |
| **齐次** | `y' = F(y/x)` | 右端每项关于 x、y 的**总次数相同** | 令 `u = y/x`，即 `y = ux` |
| **恰当（全微分）** | `M dx + N dy = 0` | 且 `∂M/∂y = ∂N/∂x` | 求势函数 `F`，使 `dF = M dx + N dy` |
| **伯努利** | `y' + P(x)y = Q(x)y^n`（n≠0,1） | 线性但右端带 `y^n` | 令 `z = y^(1-n)`，化为一阶线性 |

## 高阶常系数线性

| 情形 | 特征方程 | 通解形式 |
|---|---|---|
| 两个不等实根 `r1 ≠ r2` | `ar^2 + br + c = 0` | `C1·e^(r1·x) + C2·e^(r2·x)` |
| 重根 `r` | 判别式为 0 | `(C1 + C2·x)·e^(r·x)` ← **第二个解要乘 x** |
| 共轭复根 `α ± βi` | 判别式 < 0 | `e^(αx)·(C1·cos(βx) + C2·sin(βx))` |

## 判别口诀

> **能分就分，不能分看线性；线性不成看齐次；齐次不行验恰当。**

提醒学生：类型判别错了，后面算得再对也是白搭——这一步值得慢下来。
