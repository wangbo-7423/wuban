# 常见积分公式速查

| 类型 | 公式 |
|---|---|
| 幂函数（n ≠ -1） | `∫ x^n dx = x^(n+1)/(n+1) + C` |
| 倒数 | `∫ 1/x dx = ln|x| + C` |
| 指数 | `∫ e^x dx = e^x + C`；`∫ a^x dx = a^x / ln(a) + C` |
| 正弦 | `∫ sin(x) dx = -cos(x) + C` |
| 余弦 | `∫ cos(x) dx = sin(x) + C` |
| 正割平方 | `∫ sec(x)^2 dx = tan(x) + C` |
| 分部积分 | `∫ u dv = uv - ∫ v du` |
| 换元积分 | `∫ f(g(x))·g'(x) dx = ∫ f(u) du` |

## 积分常数 C

**不定积分永远要加 `+ C`**。每次讲不定积分，都明确问一句：
「这次有没有漏掉 C？」——这是学生最高频的失误之一。
