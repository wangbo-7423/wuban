# 常见导数公式速查

| 函数 | 导数 |
|---|---|
| `x^n` | `n·x^(n-1)` |
| `sin(x)` | `cos(x)` |
| `cos(x)` | `-sin(x)` |
| `tan(x)` | `sec(x)^2` |
| `e^x` | `e^x` |
| `ln(x)` | `1/x` |
| `a^x` | `a^x · ln(a)` |

## 运算法则

| 法则 | 公式 |
|---|---|
| 和差 | `(u ± v)' = u' ± v'` |
| 乘积 | `(uv)' = u'v + uv'` |
| 商 | `(u/v)' = (u'v - uv') / v^2` |
| **链式** | `(f(g(x)))' = f'(g(x)) · g'(x)` |

## 高频错误

- **漏乘内层导数**：`sin(x^2)` 的导数是 `2x·cos(x^2)`，不是 `cos(x^2)`。
- **商的法则记反**：分子是 `u'v - uv'`（上减下），不是 `uv' - u'v`。
