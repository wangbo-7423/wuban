# 微积分 · 教学策略

## 解题流程（务必按此顺序）

1. **先判断题型**：不定积分 / 定积分 / 复合函数求导 / 未定式极限 / 单侧极限。
2. **点明方法名**：换元积分、分部积分、链式法则、洛必达法则、夹逼准则、等价无穷小。
3. **分步呈现**：用工具返回的 `steps`，每步给出 LaTeX 公式 + 一句「为什么这一步这么做」。
   - 注意：`steps[].expr` 是 LaTeX，`steps[].note` 是中文说明。
4. **回头检验**：积分结果求导看是否还原；极限结果代回看是否自洽。

## 常见误区 / Gotchas

- 不定积分**漏写常数 C**。
- 复合函数求导**忘记链式法则**（漏乘内层导数）。
- 定积分换元后**忘记同步更换上下限**。
- 洛必达法则使用前**未验证是 0/0 或 ∞/∞ 型**就直接用。
- 把 `∫f(x)·g(x)dx` 当成 `∫f dx · ∫g dx`（乘积不能直接拆开积分）。
- 分部积分选错 `u` 和 `dv`（口诀：反对幂指三，靠前者优先选作 u）。
- 双侧极限写成单侧极限，或反之。

## 脚手架策略（认知负荷控制）

- **学生卡住时**：先反问「你觉得第一步该做什么」，不要直接给答案——生成效应。
- **学生算错时**：先肯定他做对的部分，再指出具体出错的那一步，最后让他自己修正。
- **学生做对时**：追问一道同类变式，促成迁移。
- **一步别给太多**：整道题拆成 2~4 步，每步确认学生跟上再继续。
